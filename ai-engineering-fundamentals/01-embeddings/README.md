# 01 — Embeddings: How AI Represents Meaning

Learn how AI represents meaning using numerical vectors and performs semantic search using cosine similarity.

## Concepts Covered

- Limitations of keyword-based search
- Representing meaning using numbers
- Embeddings and high-dimensional vector spaces
- Embedding models
- Cosine similarity
- Semantic search and product ranking
- Model limitations and engineering considerations

## Practical Implementation

We build a simple e-commerce semantic search system using Python and a pretrained embedding model.

### Technologies Used

- Python
- Jupyter Notebook
- Sentence Transformers
- all-MiniLM-L6-v2
- Matplotlib

### Installation

Install the required libraries:

`pip install sentence-transformers matplotlib`

## Learning Resources

The accompanying Jupyter Notebook demonstrates the complete implementation, including embedding generation, similarity calculation, product ranking, and visualization.
